# Kimi preview QA26 — 2026-09-14

Scope: isolated Kimi preview only. Original repositories, paused Codex preview, and existing services on 8174/8175/8290 were not modified.

## Changes

- Stop the lobby reconnect timer after WebSocket close 4001 (same account opened in another tab). Temporary network loss still retries. Applied to the main scene and all five active mini-game bundles.
- Display a clear tab-takeover notice instead of an endless reconnecting message.
- Only offer car entry when the car is stopped and the character is within the server's permitted vertical range.
- Match the dedicated Kimi server's added coast collision floor to the exact coast24 render triangles. Original terrain is retained outside that patch.
- Connect this preview to the dedicated Kimi-only Mac mini service on 8292. Existing shared service remains untouched. Public access still depends on the Mac and a temporary tunnel; this is not permanent hosting or a no-outage guarantee.
- Version updated imports together to avoid mixing old and new runtime modules from cache.
- Repair archived Balloon/Basket/Penalty routing: `legacyGames=1` preserves the old scene instead of redirecting its card to the active online game. Normal Play & friends routing is unchanged.

## Verified

- Main scene: desktop chat bubble above character; mobile-width chat bubble above character; emote panel closes on selection; white joystick visible.
- 1,000 rapid F key presses followed by a visible jump without a captured runtime error; 100 rapid mobile-width Punch button clicks followed by a visible jump. This is not a real iPhone endurance test.
- Unit endurance: 1,000 punch cycles / 60,000 animation frames, stable action count; bot recoil/knockdown/recovery; chat 1,000 messages / 6,000 projection steps with bounded DOM and fault recovery.
- Camera/touch unit cases: left/right mouse drag, touch ownership, cancellation and 1,000 repeats. Rally simultaneous gas/steer, finger sliding, independent release and cancellation pass.
- Main scene car entry and exit visibly confirmed; overview single-click and zoomed double-click changed the player position and returned to walking.
- Two-tab takeover visibly confirmed: first tab stops reclaiming the socket; second remains connected.
- Ten separate WebSocket sessions on local and public Kimi service: common island, chat to ten clients, four unique car seats, excess claims rejected, passengers cannot drive, driver moves car, four exits, session resume and origin/token isolation. These were automated sessions from one host, not ten physical phones or ten distinct IPs.
- Public test initially had an ECONNRESET and one exit timeout. A later complete public run passed (driver distance 4.44 m). Back-to-back test sessions also temporarily filled the 20-second reconnect-grace slots; after grace expired the single-island test passed. These failures are retained here, not treated as proof of perfect network reliability.
- Coast: 1,504 server-floor triangle samples agree within 0.001 m; unrelated sampled terrain unchanged. Separate coast24 visual/collider test: 1,497 samples, original geometry prefix preserved, idempotent repair.
- Basket: five-shot result and restart; penalty: original court loads and bot turns advance. Race: three-bot start, clock and lap advancement. Balloon: result, replay and dash cooldown. Rockets: bots score, attack reload and skill cooldown after input. No captured JS errors in sampled mini-game UI states.
- Simulation tests: complete basket/penalty rounds, disconnect termination, four-vehicle three-lap race, 150-second balloon and rockets simulations with finite state and bounded event/projectile counts.
- Cosmetic tests: 20 combinations, 200,000 updates, at most two added draw calls per avatar, disposal/reduced-motion paths.
- Sampled layouts: 320x568, 390x844, 844x390 and normal desktop. Not every browser/device or viewport size.
